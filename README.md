## Minha metodologia com IA

Utilizo IA para fazer o trabalho bruto, gerar blocos de código, recomendações e automatizar funções que normalmente tomariam muito tempo, como relatórios de desempenho e testes de QA.

1. **Formação do Handout:** Após descrever um design funcional, vou detalhando o funcionamento de cada parte do projeto, até chegar em seus detalhes, os quais são compilados em um documento de Design chamado Handout, que será passado para a IA iniciar a avaliação de viabilidade, e realizar as recomendações de correções para o projeto. Caso esteja pronto, com aprovação minha ou do cliente, entrego para um novo agente para que o desenvolvimento comece.

   <img width="1380" height="1679" alt="handout-the-vast" src="https://github.com/user-attachments/assets/e7288413-c818-47fb-95ad-a66b09ed21d4" />


2. **Estruturação e desenvolvimento:** Caso o projeto demonstre flexibilidade na sua estrutura, defino a ordem de desenvolvimento junto com a IA, priorizando estabilidade. Caso contrário, uma seção no Handout incluirá a ordem e estrutura a se seguir no desenvolvimento, com fases pausadas, onde entre elas são realizados os testes de QA de cada feature, até receber aprovação minha ou do cliente para que o desenvolvimento siga para a próxima fase.
   
   <img width="1380" height="921" alt="handout-ordem-desenvolvimento" src="https://github.com/user-attachments/assets/c113da06-fd03-4123-9cbc-5328f0815aa9" />


3. **Revisão e testes:** Após a aprovação dos testes de funcionalidade no Handout, seguimos para a revisão e os testes do projeto completo. São testes manuais e automáticos, como os feitos durante o desenvolvimento, porém mais a fundo, procurando falhas, bugs e brechas de segurança, tudo documentado e rotulado.
   
   <img width="1893" height="1569" alt="nova-line-relatorio-testes" src="https://github.com/user-attachments/assets/bf0a2f12-e5b9-4326-8aaa-a421e0c621bf" />


4. **Finalização e aprovação:** Um compilado do histórico de desenvolvimento do projeto é formulado, assim como uma documentação de guia de uso é feita para o projeto, sendo assim entregue para o cliente juntamente com o projeto, esperando sua aprovação ou pedido de modificação.
